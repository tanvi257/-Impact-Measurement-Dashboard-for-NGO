# NSS Challenge 5.1 - NGO Impact Measurement Dashboard

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://x5uyfkyl9jr6sbqegdqsov.streamlit.app/)


This project is a complete prototype for Challenge 5.1: Impact Measurement Dashboard for a Partner NGO.

It converts raw field activity data into decision-ready KPIs for non-technical NGO staff:

- Cost per improved beneficiary
- Programme progress
- Demographic reach
- Outcome score gain
- Data quality issues
- District and programme comparisons
- Simple impact projection

## Why sample data is included

The challenge allows a sample or anonymized real dataset. Since no real NGO data was provided, this project includes a synthetic anonymized dataset generated by `generate_sample_data.py`.

If real NGO data becomes available, upload it from the dashboard sidebar or replace `data/sample_field_data.csv` with a CSV following `data_dictionary.csv`.

## KPI logic

The KPI tree follows the activity to output to outcome to impact structure required in the brief:

| Level | KPI | Formula |
| --- | --- | --- |
| Activity | Sessions completed | sessions_completed / sessions_planned |
| Output | Beneficiaries attended | sum(beneficiaries_attended) |
| Outcome | Average score gain | endline_score - baseline_score |
| Impact | Estimated improved beneficiaries | beneficiaries_attended * positive_score_gain / 100 |
| Efficiency | Cost per improved beneficiary | total_cost / estimated_improved_beneficiaries |

## Suggested submission note

This is a reusable dashboard template for small NGOs. It can be connected to Google Sheets, PostgreSQL, or an uploaded CSV. The included sample data is anonymized and used only to demonstrate the dashboard workflow.
